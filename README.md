# Boston Housing Data Analysis

A comprehensive exploratory data analysis and statistical testing project on the Boston Housing dataset using Python.

## 📌 Project Overview
This project analyzes the Boston Housing dataset to uncover key relationships between housing values (`MEDV`) and various factors such as industrial proportion, river proximity, nitric oxide concentration, and distance to employment centers.

## 🛠️ Features & Tasks Completed
- **Data Visualization:** Boxplots, scatter plots, and histograms analyzing key features (`MEDV`, `AGE`, `NOX`, `INDUS`, `PTRATIO`).
- **Hypothesis Testing:**
  - **T-Test:** Evaluating median house values based on Charles River proximity (`CHAS`).
  - **ANOVA:** Assessing differences in home values across different age categories (`AGE`).
  - **Pearson Correlation:** Testing the linear relationship between Nitric Oxide (`NOX`) and Non-Retail Business Acres (`INDUS`).
  - **OLS Regression:** Measuring the impact of weighted distance to employment centers (`DIS`) on home values.
